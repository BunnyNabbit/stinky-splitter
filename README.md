# _Stinky splitter_

An auto-splitter for _Gassy GaoGao_.

- Auto splits! Splits at goal, or at stage transitions.
- Tracks in-game timer.
- Resets when You Reset.

## WTF?

Yeah. [It's a game](https://notes.bunnynabbit.com/Gassy-GaoGao).

## Development

- `corepack enable pnpm`
- `pnpm i`

to build : `pnpm run asbuild:release`
